Site institucional da Igreja Assembleia de Deus — Ministério Vila Linda.
- Fundo: navy `--navy` (#0D233A), texto branco. Gradiente radial via util `bg-navy-gradient`.
- Destaque: dourado `--gold` (#D4AF37). Use utilitários `text-gold`, `bg-gold`, `border-gold`.
- Tipografia: Montserrat (700–900 títulos, 400–500 corpo). Tokens `font-display`/`font-sans`.
- Cards: `bg-[color:var(--card)]` + `border-white/10`.
- Idioma do produto: pt-BR.
